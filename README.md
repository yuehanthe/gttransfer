# gt transfer reverse search
### search for classes that transfer to georgia tech!
this works much like the the [transfer equivalency table](https://oscar.gatech.edu/pls/bprod/wwsktrna.P_find_location), but just in reverse.  
or almost exactly like the (currently down) [gt transfer tool](https://github.com/dtharumia/gt-transfer-tool)  
you enter the subject, course number of the course you want at gt and optionally the state of target schools and it returns a list of all the courses at other schools that transfers in as that course.

## how to use
- for subject please type the subject code, eg. cs for computer science or chbe for chemical engineering
- course code is just the number of the course, 1301 for cs1301 or 2100 for chbe2100
- the state field is optional. keep it blank to search all states or select your home state for community college / instate tuition reasons

(ok, fine, technically all fields are optional but i highly recommend you put in parameters to subject and course code)
